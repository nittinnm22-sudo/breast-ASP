--------

Manual Build:
-------------
pip install -e .
pyinstaller lung_asp.spec --clean --noconfirm
./dist/lung_asp/lung_asp --help

=======================================================================
  DOWNLOAD METHODS
=======================================================================

Method 1: Clone the entire repository
--------------------------------------
git clone https://github.com/nittinnm22-sudo/breast-ASP.git
cd breast-ASP

Method 2: Download as ZIP
-------------------------
1. Go to: https://github.com/nittinnm22-sudo/breast-ASP
2. Click "Code" → "Download ZIP"
3. Extract the ZIP file
4. Navigate to the extracted folder

Method 3: Download individual files
------------------------------------
From GitHub, click on each file and "Download Raw File"
Maintain the directory structure as shown above

=======================================================================
  WHAT TO DO AFTER SAVING
=======================================================================

1. Open START_HERE.md and read it
2. Verify you have all dependencies installed:
   - PyTorch
   - TotalSegmentor
   - nnU-Net (nnunetv2)
   - PyInstaller
3. Run the build script:
   - Linux/macOS: ./build_full.sh
   - Windows: build_full.bat
4. Wait 10-15 minutes
5. Find your executable in dist/lung_asp/
6. Test it: ./dist/lung_asp/lung_asp --help
7. Package it for distribution


=======================================================================
  SUPPORT
=======================================================================

If you have issues:
1. Check START_HERE.md
2. Check BUILD_LOCAL.md (troubleshooting section)
3. Check BUILD_CHECKLIST.md (verify each step)
4. Look at build/lung_asp/warn-lung_asp.txt for warnings
