## ❓ TROUBLESHOOTING

### "git: command not found"
```
→ Solution: Install Git from https://git-scm.com/downloads
→ Or use: ZIP Download method (no Git needed)
```

### "Permission denied"
```
→ Check: Do you have access to the repository?
→ Try: Download ZIP instead of git clone
```

### "Cannot extract ZIP"
```
→ Check: Enough disk space?
→ Try: Different extraction tool (7-Zip, WinRAR)
→ Or: Re-download (file might be corrupted)
```

### "Where are my files?"
```
→ ZIP: Check your Downloads folder
→ Git: Check the directory you were in when you cloned
→ Search: Look for "breast-ASP" on your computer
```
